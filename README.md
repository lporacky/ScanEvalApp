ScanEvalApp is a team-developed web application designed for automated processing and evaluation of scanned documents. The system enables document upload, analysis, data extraction, and management through a user-friendly web interface and REST API. Built with Go, Gin, GORM, PostgreSQL, Docker, and OCR technologies, the application focuses on efficient document handling, data accuracy, and scalable architecture.

Most important project-related scripts can be found in internal directory.
